# Cairn Todo 石标

> 一块一块垒，走得慢也不迷路。
> *Stack one stone at a time. Find your way back.*

Cairn 是一个 Obsidian 桌面端插件。它给每个项目一张置顶的日志便签，配上番茄钟、「在跑」提醒、「下一步」和杂念收纳，帮你在把活交给 AI 的日子里，安心做好手头这一件事。

## 为什么做它

现在的一天常常是这样过的：一个 coding agent 在改代码，一个训练任务要跑到明早六点，一篇论文在等 LLM 润色，而你正在写第四件事。

每件事都不用你亲手做完，但每件事都挂在你脑子里。那个训练还在跑吗？agent 改完了没有？上次那个实验我做到哪一步了？于是你每隔几分钟切过去看一眼，切回来又要花好一会儿想起自己刚才在干什么。一天结束，忙了很久，却说不清做成了什么。

让人焦虑的往往不是活多，而是脑子里挂着太多没合上的事。

登山的人会在山路上垒一种小石堆，叫 cairn。每块石头都很小，垒起来就成了路标：后来的人顺着它走，回程的自己也顺着它找到路。

Cairn 想做的就是这些石头：

- **把挂着的事从脑子里拿出来。** 交给 AI 的活标成「在跑」，写上大概几点好，到点它来叫你，你不用一直惦记。专注时冒出来的念头记一句就放下。
- **给回来的自己留路标。** 离开一件事之前写一句「下一步」，切回来时一眼就能接上，不用重新回忆。
- **让走过的路看得见。** 每完成一个番茄，就在那条任务上垒一块 🍅。一天下来，石头就是你做过的事。

## 一天的样子

1. 点菜单栏的 Cairn 图标，选一个项目，它的日志以一张小便签浮在所有窗口之上。
2. 把光标放在「训练 DCore」上，点 ⌛，填「8 小时」。这条任务变成在跑，预计明早 6:30 完成。
3. 光标移到「写实验章节」，点番茄钟开始 25 分钟专注。便签可以折叠成一条横条，只露出倒计时。
4. 专注时想起「好像忘了设 seed」，点 💡 记一句，回到正文。
5. 番茄结束，这条任务后面多了一个 🍅。你点「写下一步…」，留下「接着写 4.2 节的消融实验」，然后去休息。
6. 第二天早上 6:30，通知弹出「⏰ 该验收了：训练 DCore」，点一下就跳到那条任务。

## 功能

### 置顶日志便签

- 在项目笔记的属性面板里点 `log` 链接，日志会在一个小窗口里打开，并始终置顶。按住 ⌘ 点击则照常在标签页打开。
- 便签可以折叠成只有标题栏的一条横条，拖动横条移动窗口，单击展开。
- 打开便签时主窗口会自动隐藏，标题栏上的按钮可以随时把它叫回来。
- 一个便签里可以开多个项目的日志标签页。下拉列表里每个项目前面会显示它还有几条没做完的任务，比如 `[3] KidneyTalk`。

### 菜单栏入口

macOS 菜单栏上有一个 Cairn 图标。点开就是项目列表，点一个项目就弹出它的便签。番茄钟计时期间，图标旁边会显示倒计时。

### 番茄钟

- 预设 15 / 25 / 45 / 60 分钟专注和 5 分钟休息，也可以自定义任意时长。
- 状态用颜色区分：专注是红色，休息是蓝色，暂停是黄色，结束是绿色。折叠后的横条整条着色，远远看一眼就知道。
- 结束时发系统通知并播放提示音，之后显示超时了多久，直到你处理它。
- 计时状态会保存，重启 Obsidian 后接着走。

### 番茄记到任务上

开始专注时光标所在的那条任务，就是这个番茄的归属。结束后插件会在任务行上写入：

```markdown
- [ ] 写实验章节 🍅[2026-11-01 09:30-09:55 25m]
```

编辑器和阅读视图里，这段只显示成一个 🍅，悬停能看到时间。同一条任务的番茄会连成一串 🍅🍅🍅。计时途中任务被打勾、编辑或挪了位置，插件也能找回它。

### 在跑

光标放在任务上，点 ⌛，输入「几小时后完成」：

```markdown
- [/] 训练 DCore ⏰[2026-11-02 06:30] 📅 2026-11-05
```

复选框变成 `[/]`（Tasks 插件的「进行中」状态）。编辑器里显示为蓝色的 `⏳ 06:30`，到点后变成橙色的 `⏰ 待验收`，同时发出通知，每条任务只提醒一次。

### 下一步

光标放在任务上，点 👣，写一句回来后先做什么。它会成为任务的第一条子项：

```markdown
- [/] 训练 DCore ⏰[2026-11-02 06:30]
	- 👉 看 loss 曲线，和 Eagle-3 对比
```

每条任务只留一条下一步，再点一次可以修改，清空即删除。

### 杂念

点 💡，写一句，回车。它会以待办的形式追加到当前日志末尾的 `## 待整理` 小节，等休息时再处理。

## 记录都是纯文本

Cairn 写进笔记的所有东西都是普通 Markdown 文本，不是链接，不进关系图，不依赖插件也能读懂：

| 内容 | 写法 |
|---|---|
| 番茄 | `🍅[2026-11-01 09:30-09:55 25m]` |
| 在跑 | `- [/] …… ⏰[2026-11-02 06:30]` |
| 下一步 | 任务下的子项 `- 👉 ……` |
| 杂念 | `## 待整理` 下的 `- [ ] ……` |

这些标记都插在 Tasks 插件的字段（⏫、📅、🔁、✅ 等）和块 id 前面，不影响 Tasks 解析。全局搜索 `🍅[2026-11` 就能找出某个月的番茄，也可以用 Dataview 统计。

## 安装

Cairn 还没有上架 Obsidian 社区插件市场，目前可以这样安装：

- **BRAT**：装好 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件后，选择 Add Beta plugin，填入 `longyongchao/Cairn`。
- **手动**：从 [Releases](https://github.com/longyongchao/Cairn/releases) 下载最新版的 `main.js`、`manifest.json`、`styles.css`，放进 vault 的 `.obsidian/plugins/cairn-todo/`，重启 Obsidian，在 设置 → 第三方插件 里启用 Cairn Todo。

## 使用约定

Cairn 默认按下面的约定识别项目和日志，每一条都可以在设置里改：

- **项目笔记**：frontmatter 里有 `type: project`，并用 `log` 属性指向它的日志。

  ```yaml
  ---
  type: project
  log: "[[KidneyTalk 日志]]"
  ---
  ```

- 设置了 `archived: true` 的项目不出现在列表里，`_templates/` 下的笔记也会被忽略。
- `log` 指向的文件不存在时，Cairn 会在 `logs/` 下自动新建一个日志。
- 日志就是普通笔记，用 `- [ ]` 写任务即可。

## 设置

| 设置 | 默认值 | 说明 |
|---|---|---|
| 项目笔记的识别属性 | `type` = `project` | 属性值是列表时，包含该值即可 |
| 日志属性 | `log` | 项目笔记里指向日志的属性 |
| 归档属性 | `archived` | 为 `true` 的项目不出现在列表里 |
| 日志文件夹 | `logs` | 日志不存在时新建到这里 |
| 排除的文件夹 | `_templates` | 多个用逗号分隔，留空则不排除 |
| 杂念记到哪个小节 | `## 待整理` | 没有这个小节就在日志末尾新建 |
| 菜单里的专注时长 | `15, 25, 45, 60` | 单位分钟，上次用过的时长会自动补进菜单 |
| 完成时播放提示音 | 开 | 番茄钟菜单里也能切换 |

除「排除的文件夹」外，清空某一项就会恢复默认值。

## 命令

以下命令都可以在 设置 → 快捷键 里绑定。「记一条杂念」最适合绑一个顺手的快捷键。

| 命令 | 作用 |
|---|---|
| 以便签打开当前项目日志 | 在项目笔记里使用 |
| 番茄钟：开始 / 暂停 / 继续 | 空闲时开始上次的专注时长 |
| 番茄钟：结束 | 放弃当前计时 |
| 标记光标所在任务为在跑 | 同 ⌛ 按钮 |
| 给光标所在任务写下一步 | 同 👣 按钮 |
| 记一条杂念 | 同 💡 按钮 |
| 显示 Obsidian 主窗口 | 便签打开后找回主窗口 |
| 切换当前窗口置顶 | 对任意窗口生效 |

## 已知限制

- 只支持桌面端，主要在 macOS 上开发和使用。置顶和菜单栏图标依赖 Obsidian 内置的 Electron remote 接口，其他系统未经测试。
- macOS 上 Obsidian 默认使用系统原生菜单，菜单里只能显示纯文本，所以待办数写成 `[3]` 前缀。
- 便签不跨重启保留。退出 Obsidian 时便签会被关掉，下次需要重新打开。
- 界面目前只有中文。
